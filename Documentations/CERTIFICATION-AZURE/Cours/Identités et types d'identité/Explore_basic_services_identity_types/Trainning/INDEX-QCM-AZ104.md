**Objectif** : 80%+ de réussite

### **Phase 3 : Gestion et Sécurité (Semaines 3-4)**
5. **QCM-6** : Surveillance (critère pour production)
6. **QCM-7** : RBAC (compliance et sécurité)

**Objectif** : 80%+ de réussite

### **Phase 4 : Révision finale (Semaine 5)**
- Reprendre toutes les séries
- Faire les QCM en conditions d'examen (30 min par série)
- Revoir les corrections détaillées pour les questions manquées

## 📖 Comment utiliser ce guide ?

### **Révision initiale**
1. Lire la fiche synthétique au bas de chaque QCM
2. Répondre aux 10 questions sans regarde les réponses
3. Consulter les corrections détaillées
4. Noter les domaines faibles

### **Pratique intensive**
1. Refaire les QCMs 2-3 fois
2. Chronométrer (max 30 min par 10 questions)
3. Viser 80%+ de réussite avant l'examen

### **Révision ciblée**
- Pour chaque question manquée, relire la section correspondante dans Microsoft Learn
- Noté les liens fournis (learn.microsoft) pour approfondir

## 🔑 Concepts clés par domaine

### **Domaine 1 : Identités (25-30% de l'examen)**
- Types : User, Service Principal, Device, AI Agent
- Scenarios : Hybrid, Cloud-only, B2B, B2C
- Managed Identities (system-assigned vs user-assigned)
- Azure AD Connect pour sync hybride

### **Domaine 2 : Ressources (20-25%)**
- Resource Groups (scope, lifecycle)
- Tags (organisation, facturation)
- Resource Manager (ARM templates, Bicep)
- Stockage Azure (types de service, niveaux, disques)

### **Domaine 3 : Réseaux (25-30%)**
- VNets, Subnets, NSGs
- VNet Peering, VPN, ExpressRoute
- Load Balancers, Application Gateway
- DNS, Private Endpoints, Service Endpoints

### **Domaine 4 : Calcul (20-25%)**
- VMs (tarification, sizing, images)
- Availability (Sets, Zones)
- Mise à l'échelle (VMSS, autoscale)
- Alternatives (Functions, ACI, App Service)

### **Domaine 5 : Gestion (15-20%)**
- Azure Monitor (métriques, logs, alertes)
- Log Analytics + KQL
- Application Insights
- Automation, Azure Policies

### **Domaine 6 : Sécurité (25-30%)**
- RBAC (rôles, scopes, custom roles)
- Key Vault (secrets, clés, certificats)
- Chiffrement (at rest, in transit, application)
- Entra ID, Managed Identities
