# QCM + corrections détaillées pour l'AZ-104 - Accès collaboratif et externalités

***

## QCM (10 questions) - Domaine : Accès collaboratif et externalités

1. **Quel service permet aux clients externes de se connecter avec leurs comptes sociaux ?**  
   a) Azure AD B2C
   b) Azure AD B2B
   c) Azure AD Connect
   d) Azure Policy

2. **Quel type d’accès est le mieux adapté pour un consultant externe temporaire ?**  
   a) Guest user
   b) Regular employee
   c) Managed identity
   d) Device identity

3. **Quel service permet d’appliquer des restrictions d’accès aux applications SaaS ?**  
   a) Conditional Access
   b) Azure Load Balancer
   c) Azure Key Vault
   d) Azure Functions

4. **Quel service Entra ID est utilisé pour la gestion des identités externes ?**  
   a) Microsoft Entra External ID
   b) Azure Site Recovery
   c) Azure Backup
   d) Azure DNS

5. **Quel rôle est approprié pour un administrateur chargé des accès utilisateurs ?**  
   a) User Access Administrator
   b) Reader
   c) Contributor
   d) Billing Reader

6. **Quel type d’identité est souvent utilisé pour une application Azure qui se connecte à une API interne ?**  
   a) Service principal
   b) Guest user
   c) Device identity
   d) B2C user

7. **Quel concept d’identité permet de conserver une copie locale du compte dans AD DS ?**  
   a) Hybrid identity
   b) Cloud only
   c) B2C only
   d) Guest identity

8. **Quel mécanisme assure la rotation automatique des identifiants ?**  
   a) Managed Identity
   b) Static password
   c) HTTP
   d) FTP

9. **Quel service permet l’authentification sans mot de passe à partir d’un appareil fiable ?**  
   a) Passwordless authentication
   b) Storage Account
   c) VPN Gateway
   d) Azure DNS

10. **Pour un accès invité, quel niveau de permission est le plus sûr ?**  
   a) Least Privilege
   b) Owner
   c) Contributor
   d) Global Administrator

***

## Corrections détaillées

1. **a) Azure AD B2C**  
   - Azure AD B2C permet les comptes sociaux pour les clients.

2. **a) Guest user**  
   - Les comptes Guest sont adaptés aux consultants temporaires.

3. **a) Conditional Access**  
   - Conditional Access restreint l’accès aux applications selon le contexte.

4. **a) Microsoft Entra External ID**  
   - Microsoft Entra External ID gère les identités externes.

5. **a) User Access Administrator**  
   - User Access Administrator gère les attributions de rôles.

6. **a) Service principal**  
   - Service principals sont appropriés pour l’accès applicatif interne.

7. **a) Hybrid identity**  
   - Hybrid identity combine AD local et Entra ID.

8. **a) Managed Identity**  
   - Managed Identities évitent les secrets permanents.

9. **a) Passwordless authentication**  
   - Passwordless authentication utilise des méthodes sans mot de passe.

10. **a) Least Privilege**  
   - Least Privilege minimise les risques d’accès.
