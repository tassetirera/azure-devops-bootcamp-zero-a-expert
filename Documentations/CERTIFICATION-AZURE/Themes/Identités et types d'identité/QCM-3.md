# QCM + corrections détaillées pour l'AZ-104 - Identités avancées et scénarios hybrides

***

## QCM (10 questions) - Domaine : Identités avancées et scénarios hybrides

1. **Dans un déploiement hybride, quel service synchronise les comptes AD local vers Entra ID ?**  
   a) Azure AD Connect
   b) Azure AD B2B
   c) Azure Site Recovery
   d) Azure Firewall

2. **Quel type d’identité Azure permet à une application d’accéder à une ressource sans secret ?**  
   a) Identité d’utilisateur
   b) Identité managée
   c) Identité d’agent IA
   d) Identité B2C

3. **Quel service est utilisé pour inviter un utilisateur externe comme invité ?**  
   a) Azure AD B2B
   b) Azure AD B2C
   c) Azure Key Vault
   d) Azure Policy

4. **Quel type d’identité correspond à un appareil Windows joint au domaine ?**  
   a) Identité utilisateur
   b) Identité d’appareil
   c) Principal de service
   d) Identité managée

5. **Quel service gère les identités pour les agents IA ?**  
   a) Azure AD Connect
   b) Microsoft Entra Agent ID
   c) Azure Firewall
   d) Azure Monitor

6. **Quel scénario correspond à Azure AD B2C ?**  
   a) Gestion de comptes clients grand public
   b) Synchronisation d’Active Directory local
   c) Partage de ressources avec partenaires
   d) Gestion de clés de chiffrement

7. **Quel type d’identité est créé automatiquement avec une ressource Azure ?**  
   a) Managed identity affectée par le système
   b) Identité d’utilisateur
   c) Identité B2C
   d) Identité d’agent IA

8. **Quel composant permet de gérer les politiques d’accès selon le contexte d’utilisateur ?**  
   a) Conditional Access
   b) NSG
   c) Load Balancer
   d) Storage Account

9. **Quel rôle Azure AD permet la gestion des utilisateurs et groupes ?**  
   a) Global Administrator
   b) Reader
   c) Contributor
   d) Network Contributor

10. **Quel service est adapté aux applications qui vendent des abonnements à des clients externes ?**  
   a) Azure AD B2C
   b) Azure AD Connect
   c) Azure Site Recovery
   d) Azure Policy

***

## Corrections détaillées

1. **a) Azure AD Connect**  
   - Azure AD Connect synchronise les comptes AD local vers Entra ID.

2. **b) Identité managée**  
   - Les identités managées permettent l’accès sans secret codé en dur.

3. **a) Azure AD B2B**  
   - Azure AD B2B permet d’inviter des partenaires externes.

4. **b) Identité d’appareil**  
   - Un appareil joint à Entra reçoit une identité d’appareil.

5. **b) Microsoft Entra Agent ID**  
   - Microsoft Entra Agent ID est conçu pour les agents IA.

6. **a) Gestion de comptes clients grand public**  
   - Azure AD B2C gère les comptes clients externes.

7. **a) Managed identity affectée par le système**  
   - Les identities system-assigned sont créées avec la ressource.

8. **a) Conditional Access**  
   - Conditional Access applique des règles basées sur le contexte.

9. **a) Global Administrator**  
   - Global Administrator gère les utilisateurs et groupes Entra ID.

10. **a) Azure AD B2C**  
   - Azure AD B2C est la solution pour les clients externes/sociétés grand public.
