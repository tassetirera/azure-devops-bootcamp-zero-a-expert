# QCM + corrections détaillées pour l'AZ-104 - Préparation à l’examen identité

***

## QCM (10 questions) - Domaine : Préparation à l’examen identité

1. **Quel service Azure fournit la synchronisation et la gestion d’identité pour Office 365 ?**  
   a) Azure AD Connect
   b) Azure Backup
   c) Azure Policy
   d) Azure DNS

2. **Quelle option est utilisée pour connecter en privé Key Vault à un réseau ?**  
   a) Private Endpoint
   b) Public IP
   c) VNet Peering
   d) ExpressRoute

3. **Quel type d’identité supporte l’authentification multi-facteur et les accès conditionnels ?**  
   a) Identité utilisateur
   b) Identité de service
   c) Managed identity
   d) Device identity

4. **Quel service sert à vérifier les permissions des utilisateurs au fil du temps ?**  
   a) Access Reviews
   b) Azure Monitor
   c) VMSS
   d) Storage Account

5. **Quel rôle Azure AD permet de gérer les applications d’entreprise ?**  
   a) Application Administrator
   b) Reader
   c) Backup Contributor
   d) Owner

6. **Quel plan est nécessaire pour utiliser Azure AD Conditional Access ?**  
   a) Azure AD P1/P2
   b) Azure AD Free
   c) Azure AD B2C
   d) Azure AD B2B

7. **Quel service Azure gère une base d’utilisateurs externes en libre-service ?**  
   a) Azure AD B2C
   b) Azure AD Connect
   c) Azure Storage
   d) Azure Firewall

8. **Quel mécanisme de sécurité est recommandé pour empêcher l’accès depuis des pays non autorisés ?**  
   a) Conditional Access
   b) NSG
   c) Load Balancer
   d) Azure Monitor

9. **Quel service permet de gérer les identités des ressources Azure (VM, App Service) ?**  
   a) Managed Identities
   b) Azure DNS
   c) Azure Load Balancer
   d) Azure Backup

10. **Quel type d’identité est utilisé pour un compte service interne avec rôle RBAC ?**  
   a) Service principal
   b) Guest user
   c) Device identity
   d) B2C user

***

## Corrections détaillées

1. **a) Azure AD Connect**  
   - Azure AD Connect synchronise les identités pour Office 365.

2. **a) Private Endpoint**  
   - Private Endpoints permettent un accès privé aux services Azure.

3. **a) Identité utilisateur**  
   - Les identités utilisateur supportent MFA et les règles d’accès conditionnel.

4. **a) Access Reviews**  
   - Access Reviews valident périodiquement les autorisations.

5. **a) Application Administrator**  
   - Application Administrator gère les applications d’entreprise.

6. **a) Azure AD P1/P2**  
   - Conditional Access nécessite une licence Azure AD P1 ou P2.

7. **a) Azure AD B2C**  
   - Azure AD B2C offre l’inscription self-service aux clients.

8. **a) Conditional Access**  
   - Conditional Access peut bloquer des connexions selon la localisation.

9. **a) Managed Identities**  
   - Managed Identities gèrent les identités des ressources Azure.

10. **a) Service principal**  
   - Un service principal est utilisé pour l’accès applicatif interne avec RBAC.
