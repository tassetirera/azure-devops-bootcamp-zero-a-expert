## Corrections détaillées

1. **b) Azure Active Directory**  
   - Microsoft Entra ID était anciennement nommé **Azure Active Directory** avant le renommage officiel en octobre 2023.

2. **b) Gérer les identités et les accès aux ressources**  
   - Entra ID est un service IAM cloud qui gère les utilisateurs, les applications et les droits d'accès.

3. **b) Une seule connexion pour accéder à plusieurs applications**  
   - Le SSO permet à un utilisateur de s'authentifier une fois et d'accéder à plusieurs applications sans se reconnecter.

4. **b) OAuth 2.0**  
   - Entra ID utilise des protocoles modernes comme OAuth 2.0 et OpenID Connect pour l'authentification.

5. **b) Une solution complète de gestion des identités et de l'accès**  
   - Entra ID ne se limite pas à un annuaire, c'est une plateforme IAM pour les services cloud et hybrides.

6. **d) Disques managés Azure**  
   - Les disques managés sont gérés par Azure Compute ; Entra ID gère l'identité et l'authentification.

7. **a) Authentification des utilisateurs**  
   - Entra ID est responsable de l'authentification, de l'autorisation et de l'accès conditionnel pour les utilisateurs.

8. **c) Authentification et autorisation**  
   - Entra ID vérifie l'identité (authentification) et contrôle ce dont un utilisateur est autorisé (autorisation).

9. **b) SSO**  
   - Le Single Sign-On offre un accès unique à plusieurs applications avec une seule authentification.

10. **b) Les environnements cloud et hybrides**  
    - Microsoft Entra ID est conçu pour les identités cloud et les scénarios hybrides avec des ressources locales ou cloud.
