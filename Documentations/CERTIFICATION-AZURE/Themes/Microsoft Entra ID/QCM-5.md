***

## Corrections détaillées

1. **c) Entra ID Gratuit**  
   - L'édition gratuite offre des fonctionnalités de base comme la gestion des utilisateurs et la collaboration B2B.

2. **c) Accès conditionnel**  
   - L'accès conditionnel n'est pas inclus dans l'édition gratuite.

3. **b) Entra ID P1**  
   - P1 inclut l'accès conditionnel, les groupes dynamiques et le SSO illimité.

4. **c) Entra ID P2**  
   - P2 ajoute Identity Protection, PIM et les Access Reviews.

5. **b) Microsoft 365 E3**  
   - L'édition P1 est incluse dans Microsoft 365 E3 et EMS E3.

6. **b) Microsoft 365 E5**  
   - L'édition P2 est incluse dans Microsoft 365 E5 et EMS E5.

7. **c) Entra ID P1**  
   - La réinitialisation de mot de passe en libre-service est une fonctionnalité de P1.

8. **c) Access Reviews et détection des risques**  
   - P2 offre des capacités avancées de gouvernance et de détection des risques.

9. **c) Identity Protection**  
   - Identity Protection est absent de l'édition gratuite et présent en P2.

10. **b) Access Reviews**  
    - Les Access Reviews font partie des fonctionnalités avancées de P2.
